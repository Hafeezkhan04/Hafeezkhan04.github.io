This folder holds the pictures that appear on your portfolio page.

Upload your images here using these EXACT filenames (case-sensitive),
and they'll automatically appear on the site — no code editing needed:

  fig-01-corrosion-detection.jpg   -> Computer-vision corrosion detection screenshot
  fig-02-ml-forecast.jpg           -> Machine-learning deterioration forecast chart
  fig-03-fem-analysis.jpg          -> Finite element analysis output (e.g. Abaqus stress plot)
  fig-04-3d-visualization.jpg      -> 3D parametric visualization render

Notes:
- .jpg, .jpeg, or .png all work — just make sure the filename (before the
  extension) matches exactly, or edit the "src=" path in index.html to match
  your file's actual name.
- Recommended size: roughly 1200x900px or similar 4:3 ratio, under 1-2MB each,
  so the page loads quickly.
- You can delete this README.txt once you've added your images — it's just
  for your reference and won't show up on the live site.
